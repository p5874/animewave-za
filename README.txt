ANIMEWAVE ZA — STARTER WEBSITE PACKAGE

WHAT IS INCLUDED
- index.html: responsive homepage and anime discovery catalogue
- styles.css: mobile-friendly dark design and layouts
- script.js: working search, genre filter, mobile navigation, current year
- privacy.html: starter privacy notice (must be reviewed/updated)
- copyright.html: copyright and takedown information template

IMPORTANT
- This is a discovery website, not a streaming host. It does not contain anime episodes.
- Provider links are generic official-service links; verify title availability in South Africa before recommending a specific provider.
- Replace hello@animewaveza.example with a real email address before publishing.
- Review the privacy and copyright pages and seek legal advice as appropriate before launch.
- The artwork on the catalogue cards is generated with CSS shapes; no official anime posters are bundled.
- This is a static website and does not include accounts, payments, a database, real-time content management, ads, or video streaming.

PUBLISHING
The files can be deployed to a static web host. Google Sites cannot import a custom HTML/CSS/JS site. For a free static host, you can use GitHub Pages, but publishing from Android requires creating a GitHub account/repository and uploading these files. Do not put copyrighted episodes on a public repository.
